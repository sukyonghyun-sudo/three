피격 연출

H 로 열고 닫기. T 로 지금 바로 맞아보기. 몬스터에게 맞으면 시체를 놓치고 son_hit 동작으로 날아간 뒤 일어납니다.

타격 연출

I 로 열고 닫기. T 로 바로 맞아보기.

소품 배치

O 로 열고 닫기. 종류 선택 → 내 앞에 놓기 → 목록에서 선택 → 화살표 버튼으로 이동(카메라 기준). 맞춘 뒤 "배치 복사" JSON을 주면 맵 기본 배치로 고정.

시체 끌기

C 로 열고 닫기. 순서대로: 잡기 → 위치 → 회전 → 다리·손 → 흔들림 → (필요하면) 관절 직접 잡기. 맞춘 뒤 왼쪽 패널 "설정 복사"로 저장.

무기 장착

U 로 열고 닫기. 장착 모드에서 [ ] 키로 프레임 이동. 무기 길이·잡는 지점·손은 모든 동작에 공통, 위치·회전은 동작별로 저장됩니다.
WASD 이동 · G 시체 잡기 · R 재시작 · Tab 설정

설정

Tab / Esc 로 패널 열고 닫기. 숫자 칸에 직접 입력 가능. 값은 자동 저장되지 않습니다. 맨 위 "💾 저장" 버튼(또는 Ctrl+S)을 눌러야 이 브라우저에 남고, "설정 복사"로 JSON을 뽑을 수 있습니다.
